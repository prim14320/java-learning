## 🔍 查找算法

| 算法 | 思路 | 时间复杂度 |
|---|---|---|
| **基本查找** | 从头到尾逐个比较 | O(n) |
| **二分查找** | 每次取中间值比较，折半缩小范围（**要求数组有序**） | O(log n) |
| **分块查找** | 先按块的最大值定位块，再在块内顺序查找 | O(√n) |

## 🔃 排序算法

| 算法 | 思路 | 时间复杂度 | 空间复杂度 |
|---|---|---|---|
| **冒泡排序** | 相邻两两比较，大的往后放，每轮确定一个最大值 | O(n²) | O(1) |
| **选择排序** | 每轮从未排序部分选出最小值，放到前面 | O(n²) | O(1) |
| **插入排序** | 把无序部分的元素逐个插入到有序部分的正确位置 | O(n²) | O(1) |
| **快速排序** | 选基准值，小的放左边、大的放右边，再递归 | O(n log n) | O(log n) |
